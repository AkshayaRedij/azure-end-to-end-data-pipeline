# 📸 Project Screenshots

This folder contains screenshots showcasing the implementation of the end-to-end Azure Data Engineering pipeline built using Azure Data Factory, Azure Databricks, Azure Data Lake Storage Gen2, Unity Catalog, Delta Lake, and PySpark.

The screenshots cover:

- Azure Data Factory Pipeline
- Azure Data Lake Storage (Bronze, Silver & Gold)
- Azure Databricks Workspace
- Unity Catalog
- Storage Credentials
- External Locations
- Bronze Layer (Auto Loader)
- Silver Layer (Data Transformations)
- Delta Tables
- Gold Layer (Delta Live Tables)

These screenshots provide a visual overview of the complete data pipeline and its core components.
